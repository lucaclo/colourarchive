- [x] **Accessibility pass**: Computed real WCAG contrast ratios (via `culori`, matching the `color-mix(in oklab, …)` formulas exactly) for `--accent-mix` and `--accent-hair` against `--bg` across all 12 chapter hue bins plus the achromatic chapter. `--accent-mix` (used for text/icons): 12.4–13.0:1 everywhere — comfortably past WCAG AAA (7:1), confirming the mix-toward-`--fg` design holds regardless of hue. `--accent-hair` (decorative border only, never text): 1.68–1.74:1 — actually *higher* than the original plain `--hair` token's 1.23:1, so no regression; hairlines were never contrast-critical by design. Also caught and fixed a real bug while checking motion: `.cover h1`'s new animation-name/-delay rule (specificity 0-1-1) was more specific than the pre-existing `.cover > * { animation: none; }` reduced-motion override (0-1-0), so under `prefers-reduced-motion: reduce` the title would have sat invisible for 220ms before popping in rather than appearing static immediately. Fixed by adding `.cover h1` explicitly to that override.
